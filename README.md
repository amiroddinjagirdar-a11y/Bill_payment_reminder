# Bill Payment Reminder System

## Project Overview
The Bill Payment Reminder System is a web-based application developed using PHP and MySQL. It helps users manage their bills and track payment due dates.

## Features
- Add bill details
- Store bill information in a MySQL database
- Track bill due dates
- Send email reminders for upcoming payments

## Technologies Used
- PHP
- MySQL
- HTML
- CSS
- XAMPP
- GitHub

## Project Files
- `index.php` – User interface and bill entry form
- `config.php` – Database connection
- `mail_sender.php` – Email reminder functionality
- `bill_reminder.sql` – Database structure

## How to Run
1. Install and start Apache and MySQL in XAMPP.
2. Import `bill_reminder.sql` into phpMyAdmin.
3. Configure database settings in `config.php`.
4. Place the project folder inside `C:\xampp\htdocs`.
5. Open `http://localhost/Bill_payment_reminder/` in your browser.
